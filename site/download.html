Get Kode

Kode for Mac

Free and open source. A disk image with the app, signed ad hoc.

Download .dmg
macOS 14.4 or later Apple Silicon All releases

Install

  1. Open the .dmg and drag Kode to Applications.

  2. Kode is not notarized by Apple yet, so Gatekeeper blocks the first launch. Clear the quarantine flag once:

    xattr -dr com.apple.quarantine /Applications/Kode.app

    or open it, then choose System Settings ▸ Privacy & Security ▸ Open Anyway.

Build from source

You need Qt 6.12, CMake 3.21+, Ninja and the Xcode command-line tools (a C++23 compiler). KDE's syntax-highlighting library comes as a submodule and is built along the way.

git clone --recurse-submodules https://github.com/rask-project/kode.git
cd kode
cmake -B build -G Ninja \
    -DCMAKE_PREFIX_PATH=/path/to/Qt/6.12.0/macos \
    -DCMAKE_BUILD_TYPE=Release
cmake --build build
open build/Kode.app

The app is signed ad hoc after the build. Move build/Kode.app to Applications to keep it.

The kode command

Like VS Code's code: in Settings ▸ Files ▸ Command line tool, click Install (macOS asks for your password once). Then:

kode .              # the current folder in the sidebar
kode src/main.cpp   # a file, in the running Kode
kode notes/new.md   # a new file, written when you save

Settings ▸ Files ▸ Default editor makes Kode open text and code files on a double click, and the Finder offers Open in Kode on a folder's or a file's right-click menu.
