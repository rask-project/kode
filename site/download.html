Kode for Mac

Free and open source. Kode is young: there is no packaged release yet, so for now you build it from source (below). Releases will appear on GitHub.

Releases on GitHub
macOS 14.4 or later Apple Silicon

Build from source

You need Qt 6.12, CMake 3.21+, Ninja and the Xcode command-line tools (a C++23 compiler). KDE's syntax-highlighting library comes as a submodule and is built along the way.

git clone --recurse-submodules https://github.com/rask-project/kode.git
cd kode
cmake -B build -G Ninja \
    -DCMAKE_PREFIX_PATH=/path/to/Qt/6.12.0/macos \
    -DCMAKE_BUILD_TYPE=Release
cmake --build build
open build/Kode.app

The app is signed ad hoc after the build. Move build/Kode.app to Applications to keep it.

Open files from the Terminal

Kode opens a file or a folder given on the command line:

open -a /Applications/Kode.app ~/Projects/aurora

The README covers the tests, the project layout and how the screenshots are made.
