A code editor that feels like a Mac.

Kode is a fast, native macOS text and code editor: syntax highlighting for more than 300 languages, splits, multiple carets, code folding and a file sidebar, in a see-through window. Typing costs the same in a 1 KB file and in a 100 MB one.

Everything in one window

Made for code, made for the Mac

Native menus, keys and dialogs, the system's colors and icons, and an editing surface written for speed.

Highlighting for 300+ languages

KDE's KSyntaxHighlighting, detected by name and shebang, with themes that follow light and dark: Kode, Atom One, ayu, GitHub, gruvbox, Solarized…

Splits, not tabs

Split side by side or top and bottom, as deep as you like. Two splits can show the same document, each with its own caret and scroll.

Multiple carets

⌃D adds the next occurrence, ⌥↑ ⌥↓ a caret above or below. Type once, edit them all, undo in one step.

Folding and blocks

Fold by the language's regions or by indentation. ⌘U selects the block around the selection, a larger one each time.

A folder in the sidebar

Open a folder and browse it as in Xcode's navigator: the Finder's icons, the file in view revealed, and new, rename, duplicate and trash in place.

Find and replace

Case-sensitive or not, regular expressions with $1 in the replacement, every match marked, Replace All in one undo.

Large files, no wait

A 100 MB file opens in 83 ms. Kode lays out and draws only the lines in view, on a piece table that never copies the text.

A real Mac document app

Open in Kode from the Finder, a kode command as VS Code's code, a sheet for unsaved changes, and your windows back when you return.

See-through and native

A translucent, blurred window, the system's accent and selection colors, SF Symbols, and light or dark as you choose.

Multiple carets

Type once. Change every one.

Put the caret on a word and press ⌃D: Kode selects it, then each next whole-word occurrence with a caret of its own. Typing, deleting, pasting and moving by word act at every caret.

  • ⌥↑ ⌥↓ add a caret on the line above or below; with ⇧, a block selection.
  • One undo step for an edit at every caret.
  • esc goes back to one caret.

Code folding

Only the code you are reading.

Fold the block at the caret with ⌥⌘← and open it with ⌥⌘→, as in Xcode, or click the markers in the gutter. A ⋯ after the line shows what is hidden; click it to unfold.

  • By the language: the folding regions of its KSyntaxHighlighting definition, or indentation for Python and YAML.
  • Never lost: going to a hidden line, finding or undoing there opens the fold.
{% include shot.html name="code-folding.gif" w=900 h=622 alt="Option-Command-Left folds a for loop, Option-Command-Right unfolds it, then a click on the gutter's marker folds and unfolds the function" %}

Select Block

Grow the selection by the code's shape.

⌘U selects the lines inside the block at the caret, then the whole block, then the one around it, up to all the text, as Qt Creator's Select Block Up. ⇧⌘U steps back.

  • ⌘/ comments the selected lines in or out with the language's own marker; ⌥⌘/ a block comment.
  • ⌃I re-indents by the brackets, comments and strings told apart.

The sidebar

Your project, the Finder's way.

Open a folder and it fills the window's sidebar: folders first, names in the Finder's order, the system's icons, and code files badged with their language. Double-click a file to open it in the active split.

  • Follows the editor: the file in view is revealed and selected.
  • File operations in place: New File, New Folder, Rename, Duplicate, Move to Trash, Cut, Copy and Paste with the Finder.
  • Open documents follow the files you rename or move.

Under the hood

QML outside. C++ where it counts.

Kode's interface is QML on Qt Quick: the windows, the splits, the sidebar, the bars and Settings. The editing surface is a C++ QQuickItem that draws straight into Qt Quick's scene graph.

  • A piece table holds the text: edits never copy it, and typing grows a single piece.
  • Only what is visible is laid out (QTextLayout) and drawn; scrolling within those lines lays out nothing.
  • Highlighting in slices of 3 ms ahead of the view, and after an edit only until a line ends as before.
  • Objective-C++ where macOS needs it, through the shared Rask modules: the see-through window, alerts, the system's colors.
  • QML
  • Qt Quick 6.12
  • C++23
  • KSyntaxHighlighting
  • Objective-C++
TextEditor.qml 
import QtQuick
import Rask.Platform

// The editing area: an EditorView filling a Flickable's
// viewport, colored with the system colors.
Flickable {
    id: root

    contentWidth: Math.max(width, view.contentWidth)
    contentHeight: Math.max(height, view.contentHeight)

    EditorView {
        id: view

        x: root.contentX
        y: root.contentY
        width: root.width
        height: root.height
        contentX: root.contentX
        contentY: root.contentY

        textColor: SystemColors.text
        caretColor: SystemColors.textInsertionPoint
    }
}
