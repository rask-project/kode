A small release for the sidebar.

## Changes

- **Move to Trash asks first.** The sidebar confirms before moving a file or
  folder to the Trash; Delete (or ⌘Delete) on the selection asks the same.
- **Keyboard shortcuts in the sidebar**, shown in its right-click menu and
  working while the file tree has the focus: Open (⌘↓), Rename (F2), Move to
  Trash (⌘Delete), Copy Path (⌥⌘C) and Reveal in Finder (⌥⌘R). Cut, Copy and
  Paste (⌘X, ⌘C, ⌘V) act on the selected file, as in the Finder.
