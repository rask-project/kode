A fix release, and the first one that updates itself.

## New

- **Updates.** Kode looks for a new release once a day, downloads it in the
  background and installs it when you quit. **Kode ▸ Check for Updates…**
  checks right away; **Settings ▸ Updates** turns the automatic checks off
  and picks the channel (stable, or stable and beta). 1.0.0 had no updater:
  install this release by hand once, later ones arrive on their own.

## Fixes

- **Each folder has its own session.** The files a folder's window had open
  are saved when it closes (and on quit) and reopen with that folder only; a
  folder opened for the first time starts empty, and Kode launched without a
  folder opens one empty window instead of every file from last time.
- **Make Default** asks macOS for the common code types only, and skips those
  Kode already opens, so it no longer asks for a hundred extensions one by
  one.
