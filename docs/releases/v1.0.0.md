The first release of Kode, a native text and code editor for macOS built in
QML (Qt Quick) and C++23.

## Highlights

- **Fast on any file.** The editing surface lays out and draws only the lines
  in view, on a piece table: a 100 MB file opens in under 0.1 s, and typing
  and scrolling cost the same as in a small one.
- **Syntax highlighting** for more than 300 languages (KDE's
  KSyntaxHighlighting), in themes that follow light and dark: Kode, Atom One,
  ayu, Breeze, GitHub, gruvbox and Solarized.
- **Splits, not tabs**, as in Qt Creator: side by side or top and bottom, the
  same document in two splits, back and forward, and ⌃Tab to switch.
- **Multiple carets** (⌃D, ⌥↑/↓), **code folding** (⌥⌘←/→, the gutter's
  markers), **Select Block** (⌘U), comments by the language (⌘/, ⌥⌘/),
  auto-indent and Re-Indent (⌃I).
- **Find and replace** with regular expressions, every match marked.
- **A folder in the sidebar**, as Xcode's navigator, with file operations in
  place.
- **Encodings and line endings** detected and kept; 20 encodings to reopen or
  save with.
- **A Mac app**: a see-through window, the system's colors and SF Symbols,
  Open Recent, unsaved-changes sheets, files reloaded when they change on
  disk, the session restored, and a right-click menu in the editor.
- **Finder and Terminal**: Open With and **Open in Kode** in the Finder, Kode
  as the default editor in one click, and a `kode` command as VS Code's
  `code` (Settings ▸ Files).
