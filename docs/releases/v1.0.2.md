A fix release.

## Fixes

- **Renaming in the sidebar** ends with Return (keeping the new name) or
  Escape (keeping the old one), names with spaces included; Return no longer
  goes on to open the file, and clicking elsewhere in the tree ends the
  rename.
- **Files that are not text** (images, archives, binaries) open in the app
  macOS uses for them instead of in the editor.
- **Bracket matching** skips brackets in comments and strings: a `)` inside
  a string no longer pairs with the `(` of the code around it.
